# Talk track — Diagram Prove Lab

Two minutes. Say first: "everything here is local — a diagram authoring tool whose walkthroughs prove what each claim means; no tenant, no network."

1. **The claim on a diagram.** "Every node can carry a claim — 'the gateway enforces this hop', 'this token is forwarded unchanged'. A diagram that asserts nothing is marketing; this one asserts and then proves."
2. **Author.** "Drag nodes, wire the edges, set each claim. Reset restores the canonical layout."
3. **Prove.** "Press Prove: the walkthrough steps each edge, shows what check fires at that hop, and marks the ones the mock actually exercised."
4. **Export.** "The HTML export keeps the walkthrough live: the customer can step it themselves without you in the room."
5. **Why it matters.** "A demo diagram and a proof are different artefacts. This lab makes the diagram carry its evidence, so the picture survives the skeptical question."
